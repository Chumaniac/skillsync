第一次检查：从一份文档开始

适合分享 Skill 前、收到技能包后或修改文档时自查。准备文件全文；无需账号或 API Key。

  1. 放入一份文档

    把 SKILL.md 全文粘贴到左侧，保留开头两条 --- 之间的字段。也可先使用内置示例。

  2. 运行格式检查

    点击“检查文档”或按 Ctrl / ⌘ + Enter，查看文档头字段和正文长度。

  3. 按结果继续

    出错时用“定位错误”返回原文。能解析只说明格式可读；目录、权限和交付物请在本机继续核验。
