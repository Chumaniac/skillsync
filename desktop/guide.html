SkillSync / 使用指南

从第一次打开，到保存结果

在运行 Skill 之前，检查目录、兼容性、权限和交付证据。

01

打开工作台，先使用内置示例熟悉检查结果；正式检查时选择自己的 Skill 目录。

02

先阅读问题、位置、依据和兼容性条件。检查通过只表示所检查的规则通过，不是执行安全保证。

03

需要修改时先预览计划，确认后才应用；保存报告并和历史批次比较。可在 CLI --help 中查看各命令的导出选项。

这件工具擅长什么

只读检查与有副作用的修复分开；支持批次、历史差异、JSON/HTML/JUnit/SARIF，报告保留原始证据。

你的资料放在哪里

工作台报告保存在 --state-dir 指定的私人目录。待检查目录由用户选择；修复必须预览并显式确认。

退出前保存当前草稿。迁移电脑时先正常退出，确认没有在途任务，再备份完整私人数据目录；不要覆盖唯一原件。

需要额外准备的条件

默认检查不运行 Skill。真实模型提供方、外网执行、Docker/microVM/远程 Worker 的合同或适配接口不能当成已启用服务。离线检查不需要 API Key。当前用户版从源码或本仓库 Release 安装，不使用可能滞后的 npm 旧版本。

遇到错误，保留原记录，先用合成示例复现；不要上传访问文件、真实原稿或完整环境配置。源码与更多说明位于 github.com/Chumaniac/skillsync-app。
