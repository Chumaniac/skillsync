# SkillSync 使用说明

## 主流程

选择目录或示例 → 只读检查 → 阅读可解释问题 → 明确确认修复 → 保存/比较报告

1. 打开工作台，先使用内置示例熟悉检查结果；正式检查时选择自己的 Skill 目录。
2. 先阅读问题、位置、依据和兼容性条件。检查通过只表示所检查的规则通过，不是执行安全保证。
3. 需要修改时先预览计划，确认后才应用；保存报告并和历史批次比较。可在 CLI --help 中查看各命令的导出选项。

## 操作原则

先用合成示例验证，再导入自己的获授权资料。必填项旁的提示说明预期格式；处理时等待明确的完成/失败状态，不连续重复提交。保存后先重新打开记录核对，再导出。空状态不会伪造历史数据；错误不自动转为成功结果。

## 目录与恢复

工作台报告保存在 --state-dir 指定的私人目录。待检查目录由用户选择；修复必须预览并显式确认。

迁移电脑时先正常退出应用，确认没有在途任务，备份整个私人数据目录；安装同版程序后恢复到相同位置。不要只复制数据库主文件而漏掉 WAL、附件或规则。版本不兼容时先备份，再按显式升级检查处理，不删除数据库以“修好”程序。

## 移动端与键盘

网页提供窄屏布局与可滚动表格。桌面包运行在当前电脑，本机回环地址不能直接在另一部手机打开；这不是已部署的手机云服务。用 Tab 在控件间移动，焦点可见；降低动态效果的系统偏好会被保留。

## 能力条件

默认检查不运行 Skill。真实模型提供方、外网执行、Docker/microVM/远程 Worker 的合同或适配接口不能当成已启用服务。离线检查不需要 API Key。当前用户版从源码或本仓库 Release 安装，不使用可能滞后的 npm 旧版本。
