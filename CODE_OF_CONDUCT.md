# Code of Conduct

SkillSync is intended to be a respectful, practical, and evidence-driven project.

Participants are expected to:

- communicate respectfully and assume good intent;
- focus criticism on behavior, contracts, and evidence rather than people;
- welcome different experience levels and backgrounds;
- protect private information and never request or publish credentials;
- accept maintainer decisions made to preserve safety, reproducibility, and project scope.

Harassment, discrimination, threats, deliberate disclosure of private information, and attempts to bypass the project's safety boundaries are not acceptable.

Report conduct concerns privately through the repository's GitHub security or maintainer contact channel. Maintainers may remove content, restrict participation, or close contributions that violate this code.
